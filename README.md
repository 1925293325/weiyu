# 微语（Weiyu）

**版本：** 1.0.0  
**作者：** Lin.  
**适用：** Typecho 1.3.0 + PHP 7.4+

---

## 功能

- 前台发布图文、音乐、视频
- 点赞、二级评论
- 游客登录（本地记忆昵称/邮箱）
- 后台审核管理（仅管理员免审）
- 九宫格图片自适应
- 音乐卡片播放/暂停
- 独立路由 + 短代码双模式
- 后台可控制是否让他人发帖

---

## 安装

1. 下载插件，文件夹重命名为 `Weiyu`
2. 上传至 `usr/plugins/`
3. 后台 → 插件 → 启用
4. 启用后自动复制模板 `page-weiyu.php` 到当前主题目录（若失败请手动复制）

---

## 使用方式

### 方式一：短代码插入页面

新建独立页面，内容里写：

```
[weiyu]
```

保存即可。

> ⚠️ **兼容性说明：** 此方式依赖主题前台登录态。  
> **已测试通过：** 易航主题（自带前台登录）。  
> **其他主题：** 若主题无前台登录，短代码模式下可能无法正确识别登录状态，导致点击"发帖/点赞/评论"无反应。未逐一测试，请自行验证或改用独立路由。

---

### 方式二：独立路由（所有主题通用）

直接访问：

```
https://你的域名/weiyu
```

**体验地址：** https://bbs.linyu.live/weiyu.html
https://bbs.linyu.live/weiyu


不依赖任何主题，不依赖短代码，任何主题 100% 可用。

---

## 后台管理

后台侧边栏 → **微语管理**

- 审核/删除微语
- 管理评论
- 顶图，在「插件设置」里配置

---

## 注意事项

| 项目 | 说明 |
|------|------|
| PHP 版本 | 最低 7.4，推荐 8.0 / 8.2 / 8.4 |
| 数据库 | 自动建表，首次启用即可 |
| 审核机制 | 除管理员外，所有人发帖均需后台审核 |
| 游客发帖 | 插件设置里可开关 |
| 多主题兼容 | 短代码模式仅保证易航主题完整可用；其他主题请用 `/weiyu` 独立路由 |
